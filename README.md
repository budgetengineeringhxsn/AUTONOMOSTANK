# AUTONOMOSTANK
This project starts with a simple remotely controlled tracked vehicle based on an ESP32 microcontroller and gradually evolves into a fully autonomous robotic tank system.
The first stage focuses on manual driving using a PS5 DualSense controller connected via Bluetooth. After establishing reliable motor control and wireless communication, the platform is expanded step by step with autonomous navigation, obstacle detection, targeting systems and live video streaming.
In autonomous mode the tank follows a black line using three IR sensors while three ultrasonic sensors continuously scan for obstacles. Once an obstacle is detected, the tank stops, the self-designed and 3D printed turret rotates via servo motor toward the obstacle and a laser pointer marks it as a visual simulation of a shot. Afterwards the tank avoids the obstacle and independently finds the line again.
Power is supplied by an 11.1V LiPo battery, two BTS7960 motor drivers control the DC motors. As a final extension, an ESP32-CAM module transmits a live FPV stream via WiFi. All components were self-assembled, wired and programmed from scratch.
